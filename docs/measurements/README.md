# Measurements

Numbers, probe output, cluster settings, capability sweeps and reproductions.

An ADR states a decision and stops; when a decision rests on something measured,
the ADR links here in one line and the file carries the evidence at whatever
length it needs. Nobody has to read these. Everybody has to read the ADR.

The reports below were written between 2026-09-04 and 2026-09-05 and moved out
of `docs/gaps.md` on 2026-09-08. They are dated observations, not current
truth: a report says what was true on the day it was taken.
