# Architecture decision records

Read this table first. Descend into a file only when the one sentence is not
enough.

An ADR states a decision and what it costs. The evidence behind one lives under
[`../measurements/`](../measurements/), the argument that produced it lives in
`git log`, and the open questions live in [`../gaps.md`](../gaps.md).

Records 0001–0051 predate the shape rule in [`CLAUDE.md`](../../CLAUDE.md) and
are kept as written. Each carries a two-line **Summary:** under its title; that
is the only edit they have taken.
